# Lunar Printer

Introduces Lunar tier Printer, a new interactable which behaves as you would expect.

![showcase](https://github.com/Geritos/LunarPrinter/blob/master/LunarPrinter/Assets/showcase.png?raw=true)
![printing](https://github.com/Geritos/LunarPrinter/blob/master/LunarPrinter/Assets/printing.gif?raw=true) ![reroll](https://github.com/Geritos/LunarPrinter/blob/master/LunarPrinter/Assets/reroll.gif?raw=true)

## Compatibility

[![ls](https://ccdn.thunderstore.io/live/repository/icons/Geritos-Lunar_Scrap-1.0.2.png)](https://thunderstore.io/package/Geritos/Lunar_Scrap/)
[![qc](https://ccdn.thunderstore.io/live/repository/icons/Faustvii-QoLChests-1.3.6.png)](https://thunderstore.io/c/riskofrain2/p/Faustvii/QoLChests/)

- [Lunar Scrap](https://thunderstore.io/package/Geritos/Lunar_Scrap/): My other mod, which adds Lunar Scrap to the game. It goes hand in hand with this mod.
- [QoLChests](https://thunderstore.io/c/riskofrain2/p/Faustvii/QoLChests/): Supports highlighting, same category as other printers (duplicators).

![qol](https://github.com/Geritos/LunarPrinter/blob/master/LunarPrinter/Assets/qol.png?raw=true)
