# Lunar Printer

Introduces Lunar tier Printer, a new interactable which behaves as you would expect.

![showcase](https://imgur.com/CRGbrAE.png)

## Compatibility

- [Lunar Scrap](https://thunderstore.io/package/Geritos/Lunar_Scrap/): My other mod, which adds Lunar Scrap to the game. It goes hand in hand with this mod.
- [QoLChests](https://thunderstore.io/c/riskofrain2/p/Faustvii/QoLChests/): Supports highlighting, same category as other printers (duplicators).

![qol](https://imgur.com/3XfqwBD.png)
